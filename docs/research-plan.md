# 研改｜需求调研计划

围绕一个班的一次课程作业，访谈教师、助教或实际负责互评的人，以及有过交作业和评阅经历的学生。请受访者复盘真实案例，记录现有做法、遇到的问题和例外。

## 调研点清单

| 编号 | 调研点 | 建议对象与问题 | 负责人 |
| --- | --- | --- | --- |
| R01 | 发布作业 | 教师如何说明要求、交付格式和评价维度？学生最常误解什么？ | 赵睿妍 |
| R02 | 提交与封存 | 学生如何确认交稿成功？迟交、错交和替换提交如何处理？ | 赵睿妍 |
| R03 | 作业问答 | 学生现在到哪里提问？哪些答复需要全班看到？ | 郭芷烟 |
| R04 | 互评分配 | 教师如何分配评阅量？缺交、评阅人不足时怎样处理？ | 郭芷烟 |
| R05 | 匿名与权限 | 作者、评阅人、助教和教师分别需要知道哪些信息？ | 赵晨瑞 |
| R06 | 给出与收到反馈 | 哪类评语能指导改进？评价维度和原文位置如何对应？ | 赵晨瑞 |
| R07 | 评语追问 | 学生遇到含糊评语时怎么澄清？谁能看、谁能回复？ | 张子原 |
| R08 | 漏评与补派 | 负责人怎样发现漏评？补派后原评阅人迟交怎么办？ | 张子原 |
| R09 | 修订与回应 | 学生如何说明采纳、部分采纳或保留原方案的理由？ | 于恩熙 |
| R10 | 修订验收 | 教师怎样确认反馈落实到哪一版、哪一处？ | 于恩熙 |

## 分工与产出

- 每人领取两个调研点，在表中填写姓名。五人可各领两个；四人选八个，建议将 R03 并入 R01、R10 并入 R09，每人仍负责两个调研主题。
- 每人产出两条用户故事，每个负责的调研点对应一条。每条填写角色、目标和价值，关联调研点编号与脱敏证据，并写 Given / When / Then 验收场景。
- 每人整理访谈记录，区分观察到的事实、推断和待确认事项。汇总后提交调研报告 PR。四人组个人合计八条，另由全组共同补两条，满足第 2 课至少十条初稿的要求。
