# R01、R02 访谈纪要

- **整理依据** 按项目范围和访谈提纲编写主题问答，归纳作业发布、提交确认和版本管理需求。
- **背景与对象** 情境为一个班提交课程短报告，匿名角色设为教师 T1 和学生 S1。
- **关联材料** [R01、R02 调研报告](R01-R02.md)

## R01 发布作业

| 访谈主题 | 答复摘要 |
| --- | --- |
| 发布时需要说明哪些要求？ | 需要同时说明任务、交付格式、截止时间和评价维度，并解释各维度的具体含义。 |
| 学生怎样确认要求是否有效？ | 希望在同一作业页查看当前版本，发生更正时能看到更新时间和变更摘要。 |
| 草稿和发布后的修改怎样处理？ | 不完整要求先保留为草稿；正式更正应保留旧版，互评开始后不随意改变已引用的评价维度。 |

## R02 提交与封存

| 访谈主题 | 答复摘要 |
| --- | --- |
| 提交后怎样确认交稿成功？ | 核对已提交状态、文件名、时间和版本，重新打开页面仍能找到回执，必要时下载文件检查。 |
| 截止前传错文件或替换失败怎么办？ | 希望能确认替换，成功后明确哪版有效；格式错误或上传失败时保留原有效稿。 |
| 开始互评后应评阅哪份作品？ | 以截止时最后一份有效稿为准，任务固定引用该版本；迟交或封存后错稿需另行审批，不能直接覆盖。 |

## 整理结论

- R01 归纳为完整发布、缺项校验及要求更正留痕，对应 UC-01 至 UC-03。
- R02 归纳为提交回执、有效版本切换及封存稿保护，对应 UC-04 至 UC-06、NFC-03、NFC-05。
