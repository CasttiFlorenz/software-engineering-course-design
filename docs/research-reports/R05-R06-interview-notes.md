# R05、R06 访谈纪要

- **访谈日期** 2026 年 11 月 27 日
- **整理依据** 赵晨瑞确认访谈答复与原调研提纲中的要点基本一致。本纪要按主题归纳，未记录逐字原话。
- **背景与对象** 访谈围绕课程作业互评中的匿名、权限和反馈展开。受访者的匿名代号、实际角色和具体作业背景待补。
- **关联材料** [R05、R06 调研报告](R05-R06.md)

## R05 匿名与权限

| 访谈主题 | 答复摘要 |
| --- | --- |
| 打开评阅任务时，身份可能从哪里暴露？ | 任务列表可以使用匿名编号，下载文件名和作品封面署名仍可能暴露作者身份。 |
| 作者收到反馈后需要看到哪些信息？ | 需要知道反馈对应的作业和具体建议。遇到含糊意见时，应能回到同一条反馈继续追问。 |
| 处理漏评和分配争议需要什么权限？ | 核对漏评通常先看任务进度和缺评数量。需要解决身份归属或分配争议时，再由有权限的教学人员核对记录。 |

## R06 给出与收到反馈

| 访谈主题 | 答复摘要 |
| --- | --- |
| 哪类反馈能帮助修改？ | 带有明确位置和改进方向的评语更容易落实。笼统指出论证不足时，作者还要判断问题出在哪一段以及怎样补充。 |
| 反馈什么时候需要定位原文？ | 局部论据适合标记段落或 PDF 页码。针对文章结构等全局问题，需要能标记为整篇意见。 |
| 修订稿重排后怎样对照反馈？ | 应回到评阅时使用的旧稿。定位不可用时，可以提供已有的原文摘录和版本提示，帮助作者继续核对。 |

## 整理结论与待补信息

- R05 的答复支持检查学生可见的文件名和署名，并区分进度查看与身份查询权限。谁授权、何时查询及具体处理案例仍待确认。
- R06 的答复支持区分定位反馈与整篇反馈，并保留被评阅版本。待补具体作业格式、实际使用的工具及一条采纳或未采纳的脱敏反馈例子。
