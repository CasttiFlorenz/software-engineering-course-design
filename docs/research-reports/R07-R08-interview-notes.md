# R07、R08 访谈纪要

- **访谈日期** 2026 年 11 月 27 日
- **整理依据** 张子原确认访谈答复与原调研提纲中的要点基本一致。本纪要按主题归纳，未记录逐字原话。
- **背景与对象** 访谈围绕课程作业互评中的评语追问、漏评发现与补派展开，受访者为任课教师 T1、助教 A1 及参与过互评的学生 S1、S2。具体作业背景与案例细节待补。
- **关联材料** [R07、R08 调研报告](R07-R08.md)

## R07 评语追问

| 访谈主题 | 答复摘要 |
| --- | --- |
| 收到含糊评语时，学生现在怎么澄清？ | 多数情况下私下微信或课后当面询问评阅人，没有统一渠道，教师和助教也不掌握澄清过程。 |
| 追问希望挂在哪里、谁能看到？ | 追问应挂在具体那条评语下，评阅人据此就能找到所指内容。可见范围倾向仅作者与该条评语的评阅人，是否让教师和助教看到仍未确定。 |
| 互评截止后还要不要受理追问？ | 倾向截止后讨论串转为只读，避免评语和结论在封存后继续变化；具体时长与处理方式待确认。 |

## R08 漏评与补派

| 访谈主题 | 答复摘要 |
| --- | --- |
| 现在怎样发现漏评？ | 助教按提交名单手工核对表格，统计谁还没交评语，往往临近截止才发现，缺少过程提示。 |
| 发现漏评后怎么补派？ | 通常在班级群聊里临时找人认领，补派给谁、什么时候补派没有留记录，进度不透明。 |
| 补派后原评阅人又交了评语怎么办？ | 会出现同一份作品评语数量超过预期的情况，目前由负责人人工取舍，采纳还是丢弃没有统一规则。 |

## 整理结论与待补信息

- R07 的答复支持把追问绑定到具体评语、由对应评阅人回复，并按匿名规则展示；待补追问对教师和助教的可见范围、讨论期时长及评阅人未回复时的处理方式。
- R08 的答复支持按作品统计已收评语数提示漏评、补派留痕并限制有效评语数；待补漏评判定阈值、中期检查时点以及迟交评语的采纳规则。
- 受访者的匿名代号、角色与具体作业背景待补；本纪要未记录可识别身份的姓名、学号或群聊信息。
