# R04 查看分配给自己的互评任务

## 用户故事

作为参与互评的学生，我想在「我的互评」里看到分配给我的作品、完成状态和截止时间，以便知道还要评几份、什么时候交。

## 调研依据

受访同学曾通过 Canvas 查看和完成互评任务。我在参与互评时会先确认待评份数和截止时间。访谈也提到了收到评语后难以继续追问的问题，该发现归入 R07。[R04 调研记录](../research-reports/R03-R04.md#r04-互评分配)

## 验收标准

### 查看已分配的任务

- **Given** 教师已发布互评任务，当前学生分到两份作品，其中一份已经完成。
- **When** 学生打开该作业的「我的互评」。
- **Then** 页面显示分给该生的两份作品、各自的状态和截止时间，并显示还剩一份待评。

### 互评任务尚未发布

- **Given** 学生已经提交作业，教师尚未发布互评任务。
- **When** 学生打开该作业的「我的互评」。
- **Then** 页面提示「互评任务尚未发布」，并且不展示待评作品。
