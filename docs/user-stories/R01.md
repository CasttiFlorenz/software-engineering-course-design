# [用户故事] 教师发布作业要求

## 用户故事

作为任课教师，我想在作业页统一发布提交要求和评价标准，以便学生按同一份要求完成作业。

## 调研依据

- 来源：[R01 调研报告](../research-reports/R01-R02.md#r01-发布作业)及 [访谈纪要](../research-reports/R01-R02-interview-notes.md#r01-发布作业)。
- 发现：资料与流程分析表明，集中呈现完整要求、发布前检查缺项和保留更正记录，有助于学生核对当前有效要求。

## 验收标准

### 场景 1：教师发布作业

- **Given** 教师拥有该课程的作业管理权限，已填写作业说明、提交格式、截止时间和评价维度。
- **When** 教师确认发布作业。
- **Then** 作业状态变为“已发布”，该课程学生可在同一作业页查看上述要求。

### 场景 2：作业要求不完整

- **Given** 教师拥有该课程的作业管理权限，但草稿缺少提交格式、截止时间或评价维度。
- **When** 教师尝试发布作业。
- **Then** 系统指出缺少的字段，作业保持草稿状态，学生无法查看该草稿。
