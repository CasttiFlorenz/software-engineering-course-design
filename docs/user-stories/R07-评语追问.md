# [用户故事] 作者向评阅人追问一条含糊的评语

## 用户故事

作为被评阅的作业作者，我想在指定评语下匿名追问澄清，以便准确理解评阅人的修改意见并据此改进作业。

## 调研依据

- 来源：调研点 R07「评语追问」访谈纪要（张子原整理，对象：任课教师 T1、参与过互评的学生 S1/S2，已脱敏）
- 发现：
  - 观察到的事实：学生收到含糊评语（如"论证不够充分"）时，目前只能私下微信或课后当面找评阅人询问，没有统一渠道；（待确认：该做法是否在历届课程中普遍存在）
  - 推断：缺少公开澄清渠道会导致作者误改方向，评阅人也无法统一答复类似疑问。
  - 待确认：追问是否需要教师/助教可见；追问的时限（是否受讨论期约束）；评阅人不回复时的处理方式。

## 验收标准

### 场景 1：作者成功发起追问

- **Given** 学生 A 已登录，是该作业的作者，某条评语已发布，且该评语的讨论期未结束
- **When** 学生 A 在该评语下提交追问"你指的是第二段哪一条论据？"
- **Then** 追问出现在该评语的讨论串中
- **And** 对应评阅人能看到该追问，作者与评阅人的学生端界面及响应数据均不显示对方真实身份

### 场景 2：评阅人匿名回复追问

- **Given** 评阅人 B 已登录，是该条评语的作者，讨论期未结束
- **When** 评阅人 B 在该追问下提交回复
- **Then** 回复出现在同一讨论串中，作业作者可见
- **And** 作业作者看到的回复及接口响应均不包含评阅人 B 的真实身份

### 场景 3：其他学生尝试查看讨论

- **Given** 学生 C 已登录，既不是该作业作者，也不是该条评语的评阅人
- **When** 学生 C 打开这条讨论的链接
- **Then** 系统拒绝读取，并且响应中不包含讨论内容或参与者身份

## 关联与待确认

- 关联需求或 Issue：调研点 R07；与 R05「匿名与权限」的匿名规则需保持一致
- 待确认事项：追问是否对教师/助教可见；讨论期的具体时限；评阅人未回复时是否提醒或升级给助教
