# [用户故事] 学生确认并替换作业提交

## 用户故事

作为提交作业的学生，我想核对已交文件，并在截止前替换错稿，以便确认互评使用的是正确版本。

## 调研依据

- 来源：[R02 调研报告](../research-reports/R01-R02.md#r02-提交与封存)及 [访谈纪要](../research-reports/R01-R02-interview-notes.md#r02-提交与封存)。
- 发现：提交记录需要明确保存结果和当前有效版本。只有替换成功才切换最终稿，才能让回执、封存稿及评阅对象保持一致。

## 验收标准

### 场景 1：学生提交后核对文件

- **Given** 学生已加入课程，作业仍可提交，且文件符合要求。
- **When** 学生上传文件并确认提交。
- **Then** 保存成功后，页面显示“已提交”、文件名、提交时间和版本号，学生可下载已交文件核对。

### 场景 2：学生在截止前替换错稿

- **Given** 学生已提交第 1 版，尚未截止且未封存，该作业允许替换。
- **When** 学生上传合规的第 2 版文件并确认替换。
- **Then** 保存成功后，第 2 版成为当前最终版本，提交信息同步更新，后续互评采用封存时的最终版本。

### 场景 3：截止后未获许可仍尝试提交

- **Given** 作业已截止，学生没有迟交权限。
- **When** 学生尝试首次提交或替换文件。
- **Then** 系统拒绝并提示作业已截止；已有提交及其时间不变，原本未提交的学生仍为“未提交”。
