# R03 查看作业答疑

## 用户故事

作为准备提交课程作业的学生，我想在作业页面查看老师或助教确认的最新答复，并在找不到答案时提问，以便按正确的格式提交作业。

[R03 调研记录](../research-reports/R03-R04.md#r03-作业问答)

## 验收标准

### 提交新问题

- **Given** 学生已加入课程，作业问答仍开放。
- **When** 学生提交一个非空问题。
- **Then** 问题关联到该作业，状态为「待答复」，学生可以查到自己的问题，教师或助教可以回复。

### 查看统一答复

- **Given** 学生已加入课程，教师或助教已在该作业下发布全班可见的提交格式答复。
- **When** 学生打开该作业的问答区。
- **Then** 页面显示对应问题、当前有效的答复、答复更新时间和「统一答复」标记。
