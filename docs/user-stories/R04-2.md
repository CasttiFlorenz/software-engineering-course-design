# R04-2 在发布互评前检查评阅人数

## 用户故事

作为组织课程互评的教师，我想在发布前知道当前每份作品最多能分配几位评阅人，以便在人手不足时调整评阅量。

## 调研依据

关联调研点 R04，关注合格评阅人不足时教师如何调整安排。以下场景以「有效提交者参与评阅」为规则草案。[R04 调研记录](../research-reports/R03-R04-Research-Reports.md#r04-互评分配)

## 验收标准

### 当前人数不足

- **Given** 只有两名学生有效提交，教师设置每份作品由两人评阅，且评阅人不能评自己的作品。
- **When** 教师在发布前查看分配检查结果。
- **Then** 系统显示当前每份作品最多可分配一人，并阻止按当前设置发布。系统没有生成可供学生领取的任务。

### 调整后人数足够

- **Given** 教师已看到当前每份作品最多可分配一人的提示。
- **When** 教师把每份作品的评阅人数改为一人并重新检查。
- **Then** 系统显示分配条件已满足，教师可以继续发布。
