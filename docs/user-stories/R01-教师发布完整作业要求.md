# [用户故事] 教师发布完整的课程作业要求

## 用户故事

作为任课教师，我想在一个页面发布作业说明、交付格式、截止时间和评价维度，以便让全班学生获得一致且可核对的要求，减少因信息分散或标准含糊造成的误解。

## 调研依据

- 来源：围绕课程作业发布方式和评价标准呈现方式进行了实际调研，采用文献查阅方式了解高等教育中的评价标准与技术支持反馈。
- 发现：学生对评价标准和评价过程的理解能够通过结构化说明得到改善，学生也更重视与评价标准直接关联的信息。因此，作业发布页需要同时呈现任务要求和可理解的评价维度。

## 验收标准

### 场景 1：教师成功发布完整作业要求

- **Given** 教师已登录并拥有该课程的作业管理权限，作业草稿已填写标题、任务说明、允许的文件格式、提交截止时间和至少一个带有具体说明的评价维度
- **When** 教师点击“发布作业”并确认
- **Then** 作业状态变为“已发布”，学生端在同一页面显示上述全部信息、发布时间和当前版本号，系统记录发布人、发布时间和该版本内容

### 场景 2：必填信息不完整

- **Given** 教师已登录并拥有该课程的作业管理权限，但作业草稿缺少截止时间、交付格式、评价维度或评价维度说明中的任意一项
- **When** 教师点击“发布作业”
- **Then** 系统拒绝发布并标出缺少的字段，作业保持“草稿”状态，学生端无法查看该草稿

### 场景 3：教师修改已发布的要求

- **Given** 作业第 1 版已经发布
- **When** 教师修改截止时间、交付格式或评价维度并确认发布新版本
- **Then** 学生端显示新版本、更新时间和变更摘要，系统保留第 1 版以及本次修改人、修改时间和修改内容

## 关联与待确认

- 关联调研点：R01 发布作业
- 关联需求：
- 待确认事项：作业发布后哪些字段允许修改；重大变更是否需要重新通知全班；评价维度是否允许教师复用课程模板。
