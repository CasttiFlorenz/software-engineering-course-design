# R04-1 为已提交作品分配互评任务

## 用户故事

作为组织课程互评的教师，我想按设定的评阅人数为有效提交分配任务，以便每份作品都能收到预定数量的同伴反馈。

## 调研依据

关联调研点 R04，关注教师如何决定评阅量、处理缺交及评阅人不足。以下场景以「有效提交者参与评阅」为规则草案。[R04 调研记录](../research-reports/R03-R04-Research-Reports.pdf#page=2)

## 验收标准

### 按有效提交分配评阅

- **Given** 五名学生中四人有效提交、一人缺交。教师设置每份作品由两人评阅。
- **When** 教师发布互评任务。
- **Then** 四份作品各分到两名不同的评阅人，四位参与者各收到两项任务且没有自评。缺交者没有待评作品，也不被分配任务。

## 关联与待确认

与教师确认缺交学生是否具备评阅资格，以及评阅量是否由教师按作业配置。
